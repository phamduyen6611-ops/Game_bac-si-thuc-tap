# Bác sĩ thực tập 24h — 3D Mobile V2.1

Game web 3D mobile tĩnh.

## Chơi thử
Bản này được tối ưu cho điện thoại và có joystick cảm ứng, camera xoay, 2 tầng bệnh viện, bệnh nhân, y tá và các khoa.

## GitHub Pages
Repo đã có workflow ở `.github/workflows/pages.yml`.
Sau khi push lên GitHub, nếu Pages chưa chạy:
1. Settings → Pages
2. Source → GitHub Actions
3. Chạy workflow `Deploy static game to GitHub Pages`

## Điều khiển
- Joystick trái: di chuyển
- Vuốt màn hình: xoay camera
- Chạy: tăng tốc
- TƯƠNG TÁC: nói chuyện, ghế, khoa, thang máy

## Lưu ý
Three.js được tải từ jsDelivr nên thiết bị cần kết nối Internet.
